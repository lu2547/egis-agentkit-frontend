# 右侧面板修正

- 四个独立面板为计划、工作空间、产物和预览。工作空间通过用户级接口浏览、上传；产物通过现有会话接口读取。目录可逐级进入、面包屑返回和刷新。文件单击切到预览，返回恢复之前的列表；选中文件按用户保存于 sessionStorage，切会话及流事件刷新不清空。
- 预览读取已认证的文件字节，支持文本、Markdown、图片、PDF、隔离 HTML、本地 DOCX 和 XLSX。DOCX 内容经 DOMPurify 处理；工作簿显示前 20 表、每表 200 行和 30 列。Office 文件超过 10 MB 或无法解析时提供下载；其他未支持格式提供下载。解析在浏览器内进行，不发送到外部服务。
- 计划优先读取传入的原生 tasks_context.tasks；未结束的助手消息中已成功执行的 TaskCreate/TaskUpdate/TaskList 可叠加实时状态。缺少原生状态时从可见消息恢复，不从普通对话推断计划。AgentScope Python 和 JS 的任务工具输出格式均有测试。
- 调用方应传入 `messages` 和 `plan?: { id, subject, state }[]`，其中 plan 应取原生 state_updated 的 tasks_context.tasks，回退到会话详情中的 plan。原有 `openFile(path, area)` 保留。
- 验证：`npm test -- tests/workspacePlan.test.ts tests/officeArchive.test.ts` 与 `npm run build` 通过。Office 解析使用 mammoth 和只读的 read-excel-file；`npm audit` 报告 0 个漏洞。解析前校验 ZIP 目录并流式核验实际解压大小，限制单个条目 20 MB、总计 50 MB、1000 个条目及压缩文件 10 MB，并拒绝加密和 ZIP64。解析器本身没有可取消的统一超时。

# 首版页面与独立组件

日期：2026-11-03。前端工程固定为 egis/egis-agentkit-frontend，沿用现有 Vue3 + TypeScript + TDesign + Vite。本文是实施拆分，不表示组件已实现。后端范围见 [V1实施规划](../../egis-agentkit-app/docs/V1实施规划.md)。

保存会发布一个不可变版本。私有资源保存后可供本人使用，向他人共享时选择确切版本以及接收用户或组织组，再提交审核。用户和组织组、直接授权与共享审核由管理员管理。数据视图区分 private/shared/system。字段和状态以 [数据结构](../../egis-agentkit-framework/docs/数据结构.md) 为准。

## 1. 布局与页面

参考用户提供的 WorkBuddy 导航、资源卡片、详情弹窗、专家表单和首页输入框。产品名称、图标与内容使用 Egis 自己的资源，不复制截图中的人物头像、水印或使用次数。

```text
┌──────────────────────┬──────────────────────────────────────────┐
│ 左侧 AppSidebar       │ 右侧 MainContent                         │
│ 品牌 / 折叠 / 搜索    │ 新任务：欢迎区 + 场景 + 输入框 + 快捷提问 │
│ 新建任务              │ 聊天：消息列表 + 工具状态 + 底部输入框    │
│ 专家·技能·连接器      │ 专家：目录 / 详情 / 创建与编辑            │
│ 知识库（暂未开放）    │ 技能：目录 / 详情 / 上传与编辑            │
│ 最近任务              │ 连接器：目录 / 配置 / 连通性测试          │
│ 用户菜单              │ 个人设置 / 管理员发布包状态              │
└──────────────────────┴──────────────────────────────────────────┘
```

左栏约 240px，可折叠为图标栏；右栏填满剩余空间。窄屏左栏作为 Drawer；详情使用 Dialog/Drawer，不迫使所有页面永久增加第三栏。

| 路由 | 页面职责 |
| --- | --- |
| / | 新建任务，首次发送才创建 Session |
| /tasks/:sessionId | 原生会话消息、工具、确认/恢复、停止、交付与文件查看 |
| /experts | 专家 / 专家团目录，分类、搜索、全部 / 我的切换 |
| /experts/new、/experts/:definitionId/edit | 我的配置型专家创建/编辑；普通用户不能编辑系统或他人原件 |
| /teams/new、/teams/:definitionId/edit | 我的专家团创建/编辑，主理人、成员与协作配置 |
| /skills | 通用技能与我的技能；创建/上传、个人安装/启停、自己的内容维护 |
| /connectors | MCP 连接器目录、配置、启停、测试与工具列表 |
| /tools | 只读浏览系统默认工具和专家工具 |
| /experts?tab=personal | agent.md、soul.md、user.md 编辑与偏好配置 |
| /share-requests | 本人的共享申请与审核结果，不是管理员授权页面 |
| /admin/users、/admin/groups | admin 管理用户基本信息、user/admin 角色、Group 与成员 |
| /admin/grants | 管理员向用户或组织组授予资源版本的使用权限 |
| /admin/share-reviews | 管理员按所选版本和接收对象审核共享申请 |

知识库首版为禁用导航项，提示暂未开放，不创建可用的知识库页面。原生后端有相关能力不意味着首版自动开放。

“我的专家 / 我的专家团 / 我的 Skill”按 owner_type=user 且 owner_id=当前用户筛选。系统和他人原件只提供获授权的使用操作，编辑/删除资格由后端校验并返回 is_editable、is_deletable 等派生状态；不以隐藏按钮代替后端权限。完整目录与范围见 [Workspace与用户资源范围](../../egis-agentkit-framework/docs/Workspace与用户资源范围.md)。

admin 可以管理全部资源；普通用户不显示管理菜单，直接访问对应 API 同样拒绝。个人助理默认可用，系统资源未获 USE 时禁用召唤；管理员身份也不代表运行时 USE。完整 ReMe 管理页后续单独评审，首版不宣称已有 CRUD。

## 2. 目录分层

```text
src/
├─ layouts/                    # 左右布局与路由容器
├─ components/
│  ├─ navigation/              # 左栏独立组件
│  ├─ composer/                # 首页/会话页共用输入框与选择器
│  ├─ conversation/            # 消息、工具、确认、运行状态
│  ├─ catalog/                 # 资源目录的通用布局/筛选基础
│  ├─ experts/                 # 专家、专家团的卡片/详情/表单
│  ├─ skills/                  # 技能专属组件
│  ├─ connectors/              # MCP 专属组件
│  ├─ preferences/             # 个人文档与记忆
│  ├─ packages/                # 管理员发布包组件
│  └─ workspace/               # 文件与交付查看
├─ views/                      # 路由编排，不包含全部业务视觉实现
├─ api/                        # HTTP、原生运行 API、管理 API、流式传输
├─ composables/                # 页面状态、加载、表单提交、SSE 生命周期
├─ domain/                     # 原生事件到前端消息视图的 reducer
├─ types/                      # DTO、组件数据类型
└─ styles/                     # 布局、间距、颜色 token；具体组件 scoped 样式
```

首版先使用 Vue composable 管理局部状态；跨页的会话列表、当前身份和选择上下文集中管理，不为每个按钮建全局 Store。需要 Pinia 时以真实跨页状态为依据引入。

## 4. 首页与共用输入框

首页由 HomeGreeting、ScenarioCategoryTabs、TaskComposer、PromptStarterList 组成。场景/快捷提问来自实际定义数据或明确的产品配置，不展示不能执行的虚假推荐。

| 独立组件 | 唯一职责 |
| --- | --- |
| HomeGreeting | 标题和欢迎文案 |
| ScenarioCategoryTabs | 场景筛选与推荐提问选择 |
| PromptStarterList / PromptStarterItem | 显示快捷提问，选择后填入输入框 |
| TaskComposer | 组合输入、附件、资源选择和发送；不直接处理 SSE |
| PromptTextarea | 文本、快捷键、输入法合成状态与自动高度 |
| ComposerActionMenu | 添加文件、专家、技能、连接器的菜单入口 |
| AttachmentPicker | 文件选择，向上传逻辑发事件 |
| AttachmentList / AttachmentChip | 上传进度、失败、删除与已上传引用 |
| ResourcePickerPanel | 专家/技能/MCP 选择器共享的搜索、列表、加载状态基础布局 |
| ExpertPicker | 选择可访问的专家或专家团 |
| SkillPicker | 个人助理选择自己的可用技能；系统专家配套技能不提供独立选择/关闭开关 |
| ConnectorPicker | 选择当前任务允许使用的 MCP |
| SelectedResourceChips | 已选资源的展示和移除 |
| ModelSelector | 选择授权范围内的模型配置，不直接接触原始密钥 |
| ComposerSendButton | 发送可用/禁用/提交中状态 |
| ComposerStopButton | 发出停止事件，停止操作由 useConversation 执行 |

TaskComposer 通过 v-model/props 接收 Draft、资源选择、上传状态和运行状态，通过 emits 发出 submit/select/remove/stop。首页与会话页使用同一组件，不复制两套输入框。

选定系统专家后，不将个人助理安装/选择的 Skills 自动带给专家。自建专家以其已保存的明确绑定为准；团队成员按各自配置加载。个人助理安装新技能后，在同一对话刷新可用状态，不要求新建任务或重启服务。

## 5. 会话与交付

| 独立组件 | 唯一职责 |
| --- | --- |
| TaskHeader | 会话名称、当前专家/专家团、文件与交付入口 |
| MessageList | 虚拟/普通列表、自滚动和历史加载位置保持 |
| UserMessage | 用户文本与附件引用 |
| AssistantMessage | 编排助手文本、工具结果和完成状态 |
| MarkdownContent | Markdown 渲染、代码块和内容净化，不接收未经处理的任意 HTML |
| ToolCallCard | 工具名称、输入、执行中/成功/失败、结果折叠 |
| PermissionRequestCard | 原生人工确认及允许/拒绝事件 |
| TurnStatus | 排队、执行、等待确认、完成、取消状态 |
| StreamConnectionBanner | 断线、重连、失败与可重试状态 |
| ConversationEmptyState | 空会话的提示与快捷提问 |
| WorkspaceDrawer | 编排当前会话可访问的文件与交付视图 |
| WorkspaceFileTree | 文件目录、展开与选中 |
| FilePreview | 按允许的类型预览内容，不暴露宿主路径 |
| ArtifactList / ArtifactItem | 正式交付结果与授权下载 |

useChatStream 只管理连接和重连；domain/agentEventReducer 归并原生事件并处理事件标识/检查点，防止 SSE 重放造成重复。useConversation 负责任务提交、停止、确认恢复与状态协调。组件不自行 append 原始事件或各自新建 SSE。

发送顺序与原生 API 对齐：确保会话和订阅就绪 → 提交聊天 → 消费事件 → 展示消息与工具状态。断线恢复、历史加载、取消和人工确认均复用原生语义，不自行发明事件种类。

## 7. 技能、连接器与个人设置

| 功能 | 独立组件 |
| --- | --- |
| 技能目录 | SkillCatalogToolbar（通用/我的、搜索、新建）、SkillCard、SkillEnableSwitch（个人安装启停） |
| 技能详情 | SkillDetailDrawer、SkillDocumentViewer、SkillFileTree |
| 技能维护 | SkillCreateDialog、SkillUploadDialog、SkillDocumentEditor、SkillVersionSummary、SkillDownloadAction、SkillMarketVisibilityField；字段为 is_skill_market_visible |
| 连接器目录 | ConnectorCatalogToolbar、ConnectorCard、ConnectorEnableSwitch、ConnectorStatusBadge |
| 连接器维护 | ConnectorConfigDialog、McpTransportFields、McpHeadersFields、CredentialReferenceField |
| 连接测试 | ConnectorConnectionTest、ConnectorToolList、ConnectorToolItem |
| 个人文档 | AssistantPreferencesPanel、AgentDocumentEditor、SoulDocumentEditor、UserDocumentEditor |
| ReMe 运行设置 | 原生 middleware 的允许配置；完整管理页面与 API 后续另评审 |
| 管理员发布包 | PackageReleaseList、PackageVersionItem、PackageLoadDialog、PackageLoadStatus、PackageDisableAction |
| 用户/Group 管理 | UserManagementTable、UserRoleField（仅 user/admin）、UserGroupField、GroupManagementTable、GroupMemberList |
| USE 授权 | GrantResourceSelector（含版本）、GrantPrincipalSelector（用户或组织组）、GrantSourceList、GrantRevokeAction |
| 共享审核 | ShareReviewList、ShareReviewDecision（通过/拒绝）、ShareReviewReason |

Skill 已发布版本不能由编辑器原地覆盖；编辑后发布新版本。MCP 的密钥只展示掩码或引用，不能随表单详情返回明文。ReMe 记忆不是 memory.md 文本编辑；操作失败须显示真实错误。

is_skill_market_visible=true 在技能广场展示，false 不展示；系统 Agent 的配套 Skill 也可 true。该标志不等于共享审核通过、USE、安装、可编辑；未共享的用户私有内容不能仅凭 true 对外发布。个人安装/卸载只改自己的引用，不修改源资源；动态安装失败不能展示为已可用。

SkillVersionSummary 仅显示所选发布物版本，不代表实现 Definition 历史回退。审核页只审核共享，没有普通用户“发布审核”队列；授权页不提供 EDIT 选项。

## 8. API 与状态职责

- api/http.ts：统一鉴权上下文、错误解析与请求取消。
- api/runtime.ts：原生会话、消息、聊天、取消/确认、文件接口。
- api/manager.ts：Definition/配置视图、绑定、个人偏好、个人安装、共享申请与 admin 管理接口。
- api/stream.ts：原生 SSE 传输，不在其中维护组件显示状态。
- composables/useTaskList、useConversation、useChatStream、useComposerDraft：各自管理单一状态职责。
- composables/useExpertCatalog、useExpertForm、useSkills、useConnectors、usePreferences、usePackageReleases：管理对应加载/提交/错误状态。
- types：以 OpenAPI 契约为依据，避免前后端各自拼一套同义 DTO；组件内部可以使用清晰的 ViewModel。

默认 /api 代理到 egis-agentkit-app。现有 vite.config.ts 中独立 manager 的旧说明和 MANAGER_API_PORT 在接入时调整为 App 地址配置；同源 Cookie/可信身份方案与后端一致，前端不自行伪造正式用户。

## 9. 组件与页面验收

1. 每个有独立交互/数据含义的组件单文件；不为静态 span/图标机械拆文件，也不把全页塞进 HomeView.vue。
2. 基础输入、Card、Dialog、Drawer、Tabs、Upload、Form 等直接使用 TDesign；只对业务组合新增组件。
3. props/emits、受控状态与异步操作归属清楚；共用组件可在首页、会话页和编辑页复用。
4. 目录、表单、聊天均覆盖加载、空、失败、无权限、禁用与提交中状态。
5. 浏览器逐页检查左右布局、弹出层、长文本、窄屏、键盘交互和上传失败；关键业务流程连接真实 PG/后端/模型或明确标注的测试环境。
6. npm run build 通过；有意义的自动化用例覆盖 SSE 去重/重连、会话切换、版本切换和资源启停；不为纯样式堆镜像测试。

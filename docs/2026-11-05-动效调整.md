# 工作台动效

按用户要求直接实施，沿用现有布局、组件及接口。动效统一在 styles/motion.css 管理，采用 120ms 操作反馈、200ms 浮层、280ms 布局过渡；退出略快。优先 opacity/transform，左右栏仅在主动展开/收起时过渡宽度，拖拽时关闭缓动。

- 页面切换淡入，沿用同一会话组件，不因路由参数变化重建实例。
- 移动侧栏和遮罩滑入/淡入，桌面侧栏平滑收起。
- 工作空间固定内部宽度，外层展开收起，保留文件预览实例。
- DialogShell 统一蒙层与内容开关动画，退出时不可交互，保留原有焦点管理。
- 过程折叠使用 grid 高度过渡，不改思考内容及权限区域。
- 新消息只在首次追加时出现动画；历史加载、逐 token 更新不重复播放。
- 通过 ResizeObserver + requestAnimationFrame 跟随流式内容；手动向上滚动立即暂停跟随。
- hover/press、焦点、资源卡、产物、菜单与主题切换统一反馈。
- prefers-reduced-motion 禁用过渡、入场和滚动缓动。

验证重点：快速反复切换不会残留蒙层；拖拽无动画滞后；右栏关闭/重新打开保留选中预览；关闭后的内容不可交互；手动读历史不被流式输出拉回底部。

## 本轮已落地

- `ComposerMenu.vue` 固定主菜单尺寸，子菜单对齐当前菜单行并限制在视窗内。窄屏使用带“返回”的二级菜单；页面滚动重定位浮层，避免自动滚动误关闭。点击“从本地上传”直接触发真实文件选择器，附件仍按原接口在发送时上传。
- `PermissionModePicker.vue` 使用灰阶浮层、说明文字、图标和选中勾；完全访问权限使用橙色。保留原生五种模式及后端策略校验，失败保存维持已持久化的选择。支持键盘、关闭后焦点恢复、禁用项与“了解更多”。
- `BrandIdentity.vue` 共用深浅两套 Logo 和首页插画。横版文字调正，深色横版移除外发光。首页插画移除内嵌标语，保留放大的页面标题；输入框小机器人移除，用户头像改成姓名首字。
- 登录页 Logo 居中放在表单上方，删除欢迎语、说明与底部标语。登录字段展示为“UM账号”，认证接口仍传原有 `user_id`。
- 页面、侧栏、右侧工作空间、对话框和过程折叠共用动效节奏。流式滚动采用单个动画循环，用户滚动即暂停，主动返回底部后继续跟随。

## 权限开关来源

“完全访问权限”对应原生 `bypass`。`/manager/runtime-options` 的 `is_enabled` 由 Nacos `agentkit-policies.yaml` 中的 `allowed_permission_modes` 决定；未显式配置时默认白名单不含 `bypass`。管理员身份也不绕过白名单。灰项显示“系统策略未开放”。本轮没有自行放开策略。

如管理员决定开放，需要在该列表显式加入 `bypass`，并按现有配置批次版本规则更新、发布 Nacos 配置。该模式影响工具审批，仍不授予 Agent / Skill / MCP 等资源使用权。

## 后续界面与文档预览

- 消息头像与 favicon 统一使用 `public/brand/assistant-icon.png`，由用户提供图标通过内置 image_gen 去除外部背景，保留黑色圆角底和羊形图案。提示词要求仅去背景、不增加外发光、保持原图标。
- 会话 API 返回 `agent_display_names`：从当前会话快照读取英文内部名到中文展示名的映射。消息组件用此映射显示中文，内部 Agent 名、TeamSay 和原生消息协议不变。
- 删除首页顶部重复的新建任务图标/文字；侧栏入口保留。
- `ModelSelector.vue` 复用 Demo 的灰阶菜单结构，独立样式、深浅主题、选中标记、键盘与持久化接口兼容。
- `PdfPreview.vue` 使用本地 PDF.js Worker 与 Canvas，不调用浏览器 PDF 插件；支持翻页、缩放、中文字体资源、取消过期渲染和释放 Worker。
- PPT/PPTX、DOC、XLS、ODT/ODS/ODP 通过已授权的后台接口转换为 PDF 后预览。DOCX 使用本地文档内容预览，XLSX 使用工作表预览；文本、Markdown、HTML、常见代码扩展名继续使用各自的隔离/文本展示。
- Office 转换服务放在 framework，App 只做路由和装配。先验证用户/会话/文件路径，再转换；使用一次性目录、独立 Profile、禁止宏的设置、不继承凭据、受限排队/并发、超时杀进程组和大小限制。运行环境需要 LibreOffice 的 `soffice` 命令，当前演示环境已提供。
- PDF.js 字体、CMap、WASM 由锁定依赖在 predev/prebuild 复制到本地 public/pdfjs，不依赖外网 CDN。
- Agent 对上传文件的读取继续复用原生 Read。运行上下文补充当前任务内文件的准确绝对路径及 PDF pages 用法；不授予用户归档目录或其他会话目录的读取权。

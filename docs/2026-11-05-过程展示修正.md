# 过程展示修正

保留消息头像、中文名称、处理时长与工具总数摘要。外层过程默认收起；用户展开后，按原生消息块顺序显示“过程文字 → 活动组 → 过程文字”。连续的 thinking/tool_call 组成一组，tool_result 按调用 ID 关联，不打乱顺序、不单独占一行。活动组及参数/结果详情默认收起。

活动行使用细线列表与状态图标，去除整块灰色卡片、重复的“思考过程”标题。常用工具提供中文动作名称和文件名/查询/命令摘要。状态只由原生结果推导；已完成/失败/拒绝/停止不能继续显示执行中，缺失结果不能伪装为成功。保留输入/输出详情，不显示 base64 正文。

最后一次工具调用/思考之后的正文作为回答；后面还有工具调用的文字属于过程。状态提示单独归入过程，不会将最终回答藏进折叠区。权限请求独立于折叠区，停止后的旧确认不再出现。原生事件、消息存储、SDK appendEvent 和后端均不改动。

验证：连续与并行工具分组、文字顺序、结果关联、流式状态刷新、最终回答、终止状态、历史恢复、默认折叠、权限确认，以及深浅主题和减少动态效果。

摘要在纯正文回答完成后也继续保留，历史纯正文回答同样显示处理时长。代码审查已完成，相关问题已通过回归验证。

验证结果（2026-11-05）：40 项单元测试通过；初轮 59 项完整浏览器回归通过，补齐末尾提示与纯正文摘要后，相关 25 项浏览器回归通过。TypeScript 检查及生产构建通过（保留现有分块体积提示）。当前 5179 服务已提供新组件。

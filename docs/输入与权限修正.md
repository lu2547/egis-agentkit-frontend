# 输入与权限修正

- 输入框保留原有 props 与事件；新增可选 `isPersonal`。会话页传入真实个人助理身份后可管理个人技能与连接器；专家和身份未知的会话只提示使用预设能力。首页未选专家时使用个人能力，选中专家后不提供个人资源变更。
- 加号菜单提供附件、专家、技能和连接器。专家和资源支持搜索；资源调用现有安装/启停接口并刷新服务端状态，错误直接显示。附件仍通过既有 `attach` 事件交给上层。
- 权限卡从可折叠处理过程移至消息独立区域，仍以消息 ID 和原工具调用提交确认；出现对应工具结果后隐藏。
- 验证：`npm test`（15 项通过）；`npx playwright test tests/browser/composer-permission.spec.ts`（4 项通过，覆盖折叠后确认、菜单检索、真实启停请求与专家资源边界）；`npm run build` 通过，Vite 提示既有大 chunk 警告。

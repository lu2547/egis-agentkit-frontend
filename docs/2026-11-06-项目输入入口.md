# 项目输入入口

- 新对话首页：输入框下方左侧为项目选择器，默认使用后端 `is_default` 项目；后端尚未返回默认项目时显示“默认项目”，创建任务时由后端选择默认归属。选择其他项目后，新会话、上传和上下文候选都绑定该项目。
- 历史会话：同一位置只读显示所属项目，不能切换或移动。
- 侧边项目：增加 `+` 打开该项目新对话首页，点击项目名称仍只展开/折叠；菜单仍只有改名、删除。
- 选择项目保留输入草稿和待上传附件。选中项目被删除时回到默认项目。项目选择下拉复用灰色深浅主题，390px 窄屏不越界。

组件为 `ComposerProjectBar.vue`，样式独立于 `composer-project-bar.css`；TaskComposer 使用 footer 插槽，首页可编辑与历史只读复用同一组件。

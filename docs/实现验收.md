## 实现范围

- 240px 可折叠导航、最近任务与搜索、用户菜单；窄屏 Drawer。工作台保持白/浅灰底、黑色主按钮、Egis 祖母绿强调色。聊天为导航 / 会话 / 可调宽和收起的工作区三栏。
- 首页与会话共用 TaskComposer；英文/中文输入法组合状态、Enter/Shift+Enter、明确发送/停止状态、模型选择、专家选择、工作文件附件。首次发送前创建 Task，附件上传后只引用授权相对路径。
- 专家 / 专家团目录、分类、搜索、全部 / 我的、来源和 USE 状态、卡片、独立详情弹窗、快捷提问、成员列表、本人创建 / 编辑。字段保留 `agent_name/agent_display_name` 和 `team_name/team_display_name`。团队编辑从详情读取可编辑主理人配置；成员只选择 expert。
- Skill 通用 / 我的目录、明确版本详情、Markdown、ZIP 上传、发布新版本、授权下载、安装与启停。Skill ZIP 上传和安装 / 启停均显式传递版本。
- MCP 目录、版本配置、凭据引用、安装 / 启停、真实连接测试与工具列表。成功状态仅来自服务端响应。
- 登录、个人助理 agent.md / soul.md / user.md、本人共享申请和冻结快照；admin 用户 / 用户组 / USE 授权 / 共享审核 / 包加载和明确版本停用。普通用户不实例化管理组件。
- 36 个独立业务组件；视图负责路由编排，HTTP、SSE、事件归并、局部状态各自分层。TDesign 按所用组件导入；字段标签关联到实际输入控件以支持键盘与辅助技术。

## 原生聊天与文件边界

`src/domain/agentEventReducer.ts` 直接使用 `@agentscope-ai/agentscope` 的 `appendEvent` 和消息工厂。保留原生事件类型、reply_id、工具输入 / 结果、确认和终止语义；没有另一套聊天循环，也没有生产模拟回复。

先加载原生历史和 event_cursor，再建立 SSE，连接就绪后 POST `/chat/`。重连从历史检查点重放，按原生事件 id 去重。确认恢复同 reply_id 时重用消息；SDK 原地修改后发布新的消息 / content 引用，使 Vue 子组件及时重算。切换会话取消旧历史与订阅，并阻止旧确认、请求结果发布到新会话。

消息界面包括处理时长、可折叠过程、思考、工具活动、正文 Markdown、错误与停止。团队成员人工确认使用原生 CUSTOM 投影，确认仍向领导会话发送原生 `USER_CONFIRM_RESULT`。

右侧工作区按 work / artifacts 浏览，交付卡片可打开预览。文件请求使用 URLSearchParams 编码 `area/path`，下载和预览先通过 Bearer 授权 fetch 获取响应，不把令牌放进 URL。Markdown 通过 DOMPurify 净化；HTML iframe 使用 `sandbox=""`，未授予脚本或同源权限。临时 blob URL 在切换 / 卸载后释放。

完整方法、路径、请求字段与扩展契约见 [API调用清单](API调用清单.md)。
